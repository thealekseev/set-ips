# 🌐 Интерактивный менеджер IP-адресов и DNS-серверов для Netplan - Set-IPs

## 📋 Описание
Безопасный интерактивный bash-скрипт для управления IP-адресами и DNS-серверами через Netplan. Автоматические бэкапы, умный откат (`netplan try`), валидация YAML и защита от потери SSH-доступа.

## 🚀 Установка и запуск

> ⚠️ **ВАЖНО:** Скрипт изменяет сетевые настройки сервера. Хотя он имеет встроенные механизмы защиты, **настоятельно рекомендуется** иметь резервный доступ к серверу (VNC-консоль или IPMI) на случай потери сетевого соединения.

### Вариант 1: Скачивание и ручной запуск (Рекомендуется) 🔒

Этот способ позволяет проверить содержимое скрипта перед его выполнением.

```bash
# 1. Скачать скрипт в текущую директорию
curl -fsSL -o set-ips.sh https://raw.githubusercontent.com/thealekseev/set-ips/refs/heads/main/set-ips.sh

# 2. (Опционально) Просмотреть содержимое для проверки безопасности
less set-ips.sh

# 3. Сделать файл исполняемым
chmod +x set-ips.sh

# 4. Запустить от имени root
sudo ./set-ips.sh

## ✨ Возможности

### 🎯 Управление IP-адресами
- ✅ Добавление нескольких IPv4-адресов с CIDR-маской
- ✅ Удаление IP-адресов с защитой от потери доступа
- ✅ Поддержка IPv6-адресов
- ✅ Валидация формата IP (защита от ведущих нулей, некорректных масок)
- ✅ Автоматическое создание секции интерфейса при необходимости

### 🌐 Управление DNS
- ✅ 5 предустановленных DNS-провайдеров (Cloudflare, Google, Quad9, OpenDNS, AdGuard)
- ✅ Поддержка IPv4 и IPv6 DNS-серверов
- ✅ Ввод пользовательских DNS
- ✅ Очистка DNS-настроек
- ✅ Тест резолвинга через `nslookup` / `getent`

### 🛡️ Безопасность и надёжность
- 🔒 **Автоматические бэкапы** с правами `600` перед каждым изменением
- 🔒 **Безопасный режим `netplan try`** с автооткатом через 120 секунд
- 🔒 **Защита SSH-сессии** — предупреждение при попытке удалить IP, через который вы подключены
- 🔒 **Полный откат** при любой ошибке (YAML, `netplan generate`, `netplan apply`)
- 🔒 **Конечный автомат состояний** — честные сообщения о результате операции
- 🔒 **Защита от дубликатов** IP-адресов
- 🔒 **Защита от удаления последнего IP** с расширенным подтверждением

### 🎨 Интерфейс
- 🎨 Цветной вывод с эмодзи
- 🎨 Анимированный спиннер с таймером выполнения
- 🎨 Интерактивные меню с валидацией ввода
- 🎨 Стартовая сводка по всем интерфейсам
- 🎨 Диагностика через `netplan status` и `systemctl`
